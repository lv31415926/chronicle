怎么读这条时间轴

上下两条轨道共用同一个时间坐标：中国编年史向上生长， 世界编年史向下生长。中间那条虚线是「关联桥」—— 悬停或选中任一条目，它在另一条轨道上的同期关联事件会被点亮。

星河

两条基线之下各有一条河：河面明暗随该段史实密度涨落——事件密的年份水色浑厚，空白处水色清淡； 水面有两道交错的波光，星子顺着时间方向（自左而右）漂流，越靠近基线越密，像从河里浮起来的年头。 顶栏「星河」可关；系统里开了「减弱动态效果」时它不动，只留一幅静水；打开全屏长河时自动停帧，不占后台算力。

时间区间

顶栏两个输入框直接写年份（前636、-636 或 636，回车生效），预设可一键取 全程 / 当前视野 / 选中年所在世纪 / 所在时代 / 近 100 年 / 近 500 年。区间是全局筛选，与维度、重要度同级， 主时间轴、年份档案、双线对照与长河都跟随它；下方「全程缩览」例外——它始终画公元前 3000 至 2026 的完整密度，好让你看得见 被区间切掉的部分。区间与你滚轮调出的视野是两件事：设区间会带着镜头飞过去，缩放镜头则永不改动区间。 设置会存入本机，刷新后仍在。

长河视图

把检索命中的事件铺成一条可通读的竖直流：分节粒度随年份跨度自适应（世纪 / 十年 / 单年，按重要度排序时不分节）， 顶部目录列出各节并标出条数以显疏密。三个开关——长河始终只铺当前时间区间内的条目，「仅当前筛选」再叠上维度、 轨道与重要度门槛（从检索或主题线进入时默认不勾，全览模式默认勾选），「排序」在时间与重要度间切换， 「区间 ±20%」把区间向两端各放宽两成（至少十年，可连点），用来找回被区间切掉的流首流尾。入口有四处—— 检索面板的「铺成长河」（或 Shift+Enter）、主题线浮窗的「铺成全屏长河」、顶栏的长河按钮与 R， 以及开场那颗「进 入 长 河」：裸地址进来时首屏就落在全览（关闭 ✕ 即回时间轴）， 带深链进来时不动，仍回到你点进来的那一处。 地址形如 #/river/关键词，可直接分享或回退。

看点：本站有明确立场，但立场只在这一层

顶栏「看点」（或 G）列出本站策展的成就条目。每张卡片把四件事摊在同一屏： 本站主张（编辑立场）、条目原文（逐字引自该条目的正文，由 tools/validate-frame.mjs 校验确实出现过）、对照（同期或后继的另一轨条目）、 争议与限度（反例、归因口径、不能说到哪里）。 事实层（标题、摘要、详情、出处）不因立场而改动；比较用了「最早／第一／领先／之最」， 就必须同时给出判据、范围与强度，强度不是「确证」的必须写争议。

小故事：这一层自己写句子，所以把底本一并印在卡上

顶栏「故事」（或 S）收录历史上的小故事、人物故事与朝代趣事，每条都挂在一条真实条目上， 卡上写明系年与「看条目出处」。四张卡最大的区别不是好不好看，而是能不能当史料引用—— 史载（史书这样写了，不等于事就是这样）、笔记异闻（只有一份或少数几份记述，无从对校）、 后世附会（在流传里才成形，照样值得看，只是不能引用）、出土文献与档案（有实物或原件可指）。 引文分两种：原文逐字取自卡末列出的出处，且出处给到可直接翻到的篇目/卷册/节页/日期/著录编号； 大意是本站按原意转述，别当引文用。每张卡都带一句「为什么这样标」， 写清这条的记述凭什么、哪里存疑。正文复述一律是本站所写，不替史料说话。

点开任意条目详情的「此事的小故事」看到的是同一批卡；地址形如 #/story/st-han-001 可直接分享。

涟漪：这一层在编因果，所以先把「谁在说这句话」摆在读者眼前

顶栏「涟漪」（或 B）收录的是大事的余波落在后来的小事上这一类链条：一条链 3–6 环， 年份严格递增，末环（落点）必须是当时看来很小的事——落点本身是大事，那就只是另一份大事年表。 关键在每边连接右上角那两个字：有出处指本站据以连接的材料名，这个名字逐字出自这一边两端条目 自己列出的出处，印在边下方可以直接去翻，它说的是「据以连接」，不是「史书这样写了这条因果」； 本站的连接指这一边是本站连的——先后可考，没有哪份史料把这两件事说成一件事。 两种标记一样醒目，因为这一层最怕的就是读者把后者读成前者。每条链末尾那句「这条链哪里站不住」 是内容的一部分，不折叠、不做成脚注。邻近不是因果：同一批年表里挨着的事，本站不排成涟漪。

点开任意条目详情的「此事牵出的涟漪」会指出它在这条链的第几环；地址形如 #/chain/ch-ancient-001 可直接分享。

此后：一条读成五条，但只承诺时间

详情底部三格——三年后（本条之后 1–3 年、同一轨）、三十年后（4–30 年、同一轨且同一维度， 名额从最远的年开始往回收，所以这一格真是几十年后而不是五年后）、这些人后来（30 年内 与本条关键人物同名的条目，跨轨也算）。三格全由年份与人物名现算，不读 related， 也不写进数据；行内给出实年，年差可以当场验算。它排的是时间，不是因果——窗口里空着就不出这一格， 绝不拿一件更远的事来充数。

历史上的今天：这一页一个日期都不生产

顶栏「今天」（或 T）只列条目自己的正文里已经写明某月某日的那些事。月与日不是编辑手打的： tools/date-lib.mjs 按「标题/摘要 → 经过段 → 出处」的顺序取数，且那个年份必须等于本条的年份； 同一年里出现两个不同日子就判歧义、整条不收（这一层由 tools/validate-dates.mjs 逐字复算， 生成的 data/dates.js 与正文口径不一致就是红）。所以每条右侧标了它凭什么进这一页—— 正文纪日、经过段纪日、出处纪日（那是文书落款的那一天，不一定等于事情发生在这一天）、 中文纪日（原文写「十二月十三日」这类，只收 1912 年及以后：此前多半是农历，本库不做历表换算）。 这一天没有可核对的纪日，页面就照实说空着，只在下面列前后三日、并让每一条带着自己的日子出现。 地址里写了日历上没有的日子（#/today/4/31、#/today/13/1），页面会说这个日子不存在、 并把你送回今天——各月有几天这张表全站只有 data/dates.js 里的 mdays 一份， 谁自己抄一份就会和它打架。 早于 1583 年的公历日由后世历表推得（当时行儒略历），页脚会另说一句。

地址形如 #/today/11/6 可直接分享；「同一个号数」的一排按钮是别的月份的同一天；「铺成长河」把这一天摊成全屏。

舆图 · 地点页 · 行迹

顶栏「舆图」（或 M）把当前年代的事件落在海岸线底图上：朱砂是中国轨、石青是世界轨， 点落针开详情，点空白开该年档案。三种模式——事件（该年落针）、行迹（张骞 / 苏武 / 霍去病 / 玄奘 / 杜甫 / 苏轼的路线，站点年份可点）、大势（三个年份的势力范围示意 + 进退箭头， 只画该幅快照自己引用的那几条依据）。

底图只有海岸线与自绘水系，不含现代国界与省界；「山河大势」是示意墨面，图上写明非精确疆界。 区域级地名（语料只给到「今山西」这一级）画成软盘，不假装是精确落针。 地名与路线的出处在地点页与行迹页里逐条列出，未标「已核」的按本站口径只算「可查到哪一步」。

深链不需要坐标：#/atlas?year=-100&place=beikal、#/place/xian?year=741、 #/person/suwu；地名写古称、别名、今名都行，由本站地名表解析。

数据与口径

每条事件带维度、重要度（1–5）、摘要、详情三段（背景/经过/影响）、关键人物、地点、政权与出处。 公元前 841 年（共和行政）是中国有连续确切纪年之始，此前年代为学界推定值，一律以「~」标注。 本站只陈述事实与出处，不做价值排序。数据分片见 data/，维护与校验流程见 README.md。
